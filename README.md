# Fernando Espinosa

Software engineer in Salamanca, Spain. I've built software since 2001. These days I build and run production services with coding agents.

Some things I've made:

- [Larra](https://writer.ferdev.com): learns your writing voice from your edits and rewrites text in it. Agents such as Claude Code and Codex use it through its MCP server.
- [Herobotis](https://herobotis.ferdev.com): a playable metroidvania demo in TypeScript and Phaser about a small robot that upgrades its body to reach new areas.
- [Cosmic Atlas](https://skychart.org): a searchable atlas of 15M+ real objects from NASA, ESA and survey catalogues. Code in [skychart](https://github.com/Ferdev/skychart).
- [Monesmapa](https://monesmapa.com): an archive of 1,100+ Eugenio Monesma documentaries, with map, territory and subject browsing.
- [8bit.cafe](https://8bit.cafe): a chiptune radio built with Gleam and Lustre. Code in [8bit-cafe](https://github.com/Ferdev/8bit-cafe).

More at [ferdev.com](https://www.ferdev.com).
